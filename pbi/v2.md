**G-212 — App-dışı kişiden alınan hediye kaydı** 🟡 — ✅ giver_relation enum + XOR CHECK + alıcı-taraflı RLS (insert/update/delete, sürpriz yasak; pgTAP 44-48); Aldıklarım FAB + boş-durum CTA → ilişki dropdown'lu form (link önizleme destekli); satırda ilişki etiketi, silinmiş-üye 'Birisi' fallback'inden ayrı
- *User story:* Üye olmayan birinden (annem, babam, iş arkadaşım…) hediye aldığımda
  bunu kendi hediye geçmişime ekleyebilmek isterim — geçmişim yalnız üyelerin
  kaydettikleriyle sınırlı kalmasın.
- *Kabul kriterleri:*
  - Gifts → Aldıklarım sekmesinde "hediye ekle" aksiyonu. Form: **kimden =
    dropdown** (serbest metin YOK), hediye, tarih, isteğe bağlı not.
  - Kimden listesi (sabit, lokalize): Anne · Baba · Kardeş · Eş/Partner · Akraba ·
    Arkadaş (üye değil) · İş arkadaşı · Diğer.
  - Kayıt Aldıklarım listesinde ilişki etiketiyle görünür ("Babadan"); etiket
    profile link değildir, avatar yerine nötr ilişki ikonu.
  - Sürpriz mekaniği YOK (kendi kaydın); reveal alanları boş.
  - Hediye-geçmişi görünürlük kuralına tabi (arkadaşlar geçmişini görebiliyorsa
    bunu da görür).
  - Kullanıcı kendi eklediği kaydı silebilir/düzenleyebilir; üyelerin verdiği
    kayıtlara dokunamaz (mevcut kural değişmez).
  - Silinmiş-üye anonimleştirmesi ("Birisi") ile bu kayıtlar karışmaz — ayrı
    render yolları.
  - G-52 arkadaş-geçmişi ve G-62 suppress-if-gifted sorguları etkilenmez
    (giver_id üzerinden çalışırlar; bu kayıtlarda giver_id=null).
- *Teknik notlar:*
  - Şema: `giver_relation` enum kolonu (nullable): `mother · father · sibling ·
    partner · relative · friend · coworker · other` — UI lokalize eder, DB wire
    değeri sabit kalır (i18n'e dayanıklı; serbest metin PII/moderasyon yükü de
    getirmez, dropdown bunu tasarımda çözer).
  - Üç giver durumu: `giver_id` dolu = üye · `giver_id null + giver_relation
    dolu` = app-dışı · ikisi de null = silinmiş üye. CHECK: giver_id ile
    giver_relation aynı anda dolu olamaz.
  - RLS: ek insert policy `recipient_id = auth.uid() AND giver_id IS NULL AND
    giver_relation IS NOT NULL`; update/delete aynı koşulla recipient'a açılır;
    üye-verdiği kayıtlarda giver-only kural sürer.
  - UI: Aldıklarım boş-durumu bu aksiyona yönlendirir; ➕ quick-add sheet'ine
    satır eklenmesi değerlendirilir.
- *DoD:* Migration + pgTAP (external insert/update/delete + üye kayıtlarına

**G-211 — Link'ten zengin ürün kartı (OG metadata)** 🟡 — ✅ Edge Function `link-preview` (SSRF zırhı + rate limit + url_hash cache + görsel bucket'a server-side) canlıda; wishlist + hediye formlarında debounce'lu önizleme (X ile kaldırılabilir, sessiz düşüş, boş başlık ürün adını devralır); kartlar wishlist listeleri + hediye satırlarında; 8 deno + 6 widget testi
- *User story:* Wishlist'ime veya hediye kaydına bir ürün linki yapıştırdığımda, düz
  metin yerine ürünün adını/görselini/fiyatını gösteren bir kart görmek isterim —
  uygulama "text app" gibi değil, gerçek ürünlerle çalışıyormuş gibi hissettirsin.
- *Kabul kriterleri:*
  - Wishlist ekleme ve hediye kaydetme formlarındaki link alanına URL yapıştırılınca
    önizleme otomatik denenir (debounce'lu); başlık + görsel + (varsa) fiyat kart
    olarak formda görünür ve kayıtla birlikte saklanır.
  - Kart; wishlist listesinde, arkadaşın wishlist görünümünde ve hediye satırlarında
    render edilir (görsel + başlık; dokununca link harici tarayıcıda açılır).
  - **Zarif düşüş:** metadata alınamazsa (timeout, engelli site, OG yok) form serbest
    metin davranışına döner — hata kullanıcıyı bloklamaz, sessiz bilgi notu yeter.
  - Önizleme kullanıcı tarafından kaldırılabilir ("kartsız kaydet").
  - Boş/geçersiz URL'de önizleme denenmez; http(s) dışı şemalar reddedilir.
- *Teknik notlar:*
  - Fetch **sunucuda** (Edge Function `link-preview`): SSRF koruması (yalnız http/https,
    IP-literal/localhost/özel ağ reddi, redirect limiti), timeout (~5s), yanıt boyut
    limiti (~1MB), sadece `text/html` parse.
  - OG/Twitter-card metadata parse: `og:title`, `og:image`, `og:price:amount` +
    yaygın fiyat fallback'leri; site adı `og:site_name`/host.
  - Görsel **R2'ye kopyalanır** (hotlink kırılganlığı + izleme pikseli riski);
    WebP'ye sıkıştır (~100KB, G-207 pipeline'ını kullan).
  - Şema: `link_previews` tablosu (url_hash PK, url, title, image_path, price,
    site, fetched_at) — aynı URL tekrar çekilmez (cache + G-401 için popülerlik
    sinyali); `wishlist_items`/`gifts` → nullable `link_preview_id` FK.
  - Rate limit: kullanıcı başına dakikada ~10 önizleme (enumeration/istismar önlemi).
  - RLS: `link_previews` herkese-okunur değil; yalnız ilişkili satırı görebilen okur
    (mevcut can_view_* zincirinden türet).
- *DoD:* Uygulandı + Edge Function birim testleri (SSRF/parse/fallback) + widget
  testleri (kartlı/kartsız/düşüş durumları) + RLS pgTAP + lint temiz + iki dilde
  string'ler + her iki temada görsel kontrol (design.md).
